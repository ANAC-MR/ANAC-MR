Amorçage de l'administrateur

Transforme le compte DADY en administrateur officiel, puis met à jour tous les comptes. À utiliser une seule fois. Sans danger si tu cliques plusieurs fois.

À faire avant d'activer les nouvelles règles Firestore. Après le bouton 1, déconnecte-toi puis reconnecte-toi sur le site avant le bouton 2.
Prêt. Renseigne les deux champs puis clique le bouton 1.
1Bouton 1 : DADY reçoit le rôle admin.
2Sur le site : déconnexion puis reconnexion (le rôle entre dans la session).
3Reviens ici, bouton 2 : ré-indexe et étiquette tous les comptes.
